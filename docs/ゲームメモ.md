# フレームワーク

- React

    - プログラム作成コマンド
	    - npm create vite@latest my-react-app-- --template react
	        - my-react-appの部分はプロジェクト名
	        - ViteはReact開発環境

    - サーバーを起動するコマンド
	    - npm run dev


    - サーバーを閉じるコマンド
        - Ctrl + C

    - reactのコンポーネント
        - reactでは、基本Appコンポーネントにstateを置くことが分かった。
        - そして、他のコンポーネントを使いAppのseateを更新させるというのが分かった。
